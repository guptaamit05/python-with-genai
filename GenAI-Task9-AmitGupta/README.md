# NumPy Array and Data Analysis

## Tasks

### 1. Creating NumPy Arrays

* Create 1D and 2D arrays using arrange functions, verify dimensions, and manage integer data type allocations.

### 2. Mathematical Operations

* Perform element-wise arithmetic array calculations using standard operators and built-in NumPy mathematical functions.

### 3. NumPy Mathematical Formulas

* Apply formulas to calculate square roots, exponentials, natural logarithms, sums, and cumulative totals across data sets.

### 4. Aggregation Functions

* Execute row-wise and column-wise matrix reductions alongside finding global minimum, maximum, and mean values.

### 5. Statistical Operations

* Evaluate data distributions by computing the mean, median, variance, standard deviation, and range.

### 6. Percentiles and Sorting

* Sort data structures and pinpoint precise 25th, 50th, and 75th percentiles alongside counting values above average.

### 7. Mini Use Case: Sales Analysis

* Analyze real-world weekly tracking profiles to output sales benchmarks, highest/lowest business days, and filter data with boolean indexing arrays.

## Requirements

* Python 3.x
* NumPy library

Install Streamlit with `pip install streamlit`.

## How to Run

Open and run `numpy.ipynb` in Jupyter Notebook or VS Code.
