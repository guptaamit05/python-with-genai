# Python Exception Handling

## Tasks

### 1. Safe Division

* Handle invalid input and division by zero.

### 2. Bill Calculator

* Validate prices and handle type and value errors.

### 3. Age Validator

* Validate age using a custom exception.

### 4. Protected File Reading

* Handle missing files and access restrictions.

### 5. Safe Shopping Cart

* Validate entered prices and calculate the cart total.

## Requirements

* Python 3.x
* No external libraries required

## How to Run

Open and run `exception_handling.ipynb` in Jupyter Notebook or VS Code.
