# Streamlit Applications

## Tasks

### 1. Basic Greeting App

* Collect a name and display a greeting.

### 2. Discount Calculator

* Calculate and display a product's price after discount.

### 3. Product Form

* Enter product details and display the submitted product.

### 4. Sales Dashboard

* Select a month to view sales and compare monthly sales in a chart.

## Requirements

* Python 3.x
* Streamlit

Install Streamlit with `pip install streamlit`.

## How to Run

Run an app from the project directory:

```bash
streamlit run streamlit_assignment/app_basic.py
streamlit run streamlit_assignment/app_discount.py
streamlit run streamlit_assignment/app_product_form.py
streamlit run streamlit_assignment/app_dashboard.py
```
