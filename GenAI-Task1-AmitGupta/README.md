# Python Basic Data Structures

## Project Overview

This project contains four simple Python tasks demonstrating basic operations on built-in data structures: Set, List, Tuple, and Dictionary.

## Tasks

### 1. List and Tuple Operations

* Create a list and tuple
* update list
* convert tuple to list and add new element and convert back to tuple


### 2. Sets Operations

* Create a set, update, and print


### 3. Dict Operations

* Create a dict, update, delete and print max, min value

### 4. Combined Operations

* Create a list, iterate, print, and find max and min products list in a dict\

## Requirements

* Python 3.x
* No external libraries required

## How to Run

Run each Python file individually from the terminal:

```bash
python task_list_tuple_1.py
python task_sets_2.py
python task_dict_3.py
python task_combined_4.py
```

## Learning Objectives

* Understand Python's built-in data structures.
* Practice basic CRUD operations.
* Learn how to access, update, and iterate over collections.
