# Python Functions (User defined, Recursive, lambda, map, filter)

## Tasks

### 1. basic function()

* create apply_discount function with price and discount_percent as a default parameter that return the price after discount.
* make sure discout should be  < 60%.

### 2. recursive function()  (factorial)

* create a recursive function for calculate factorial of a number.
* handle negative value condition.

### 3. lambda function()

* calculate gst price and add it to original price
* calculate final price after applying gst and discount.

### 4. map function()
* apply gst to list of prices

### 5. filter function()

* filter expensive products from the list of products.


### 6. combined map, filter (utility) function()

* find discounted price, filtered price using map and filter functions.

### 7. mini problem : menu using functions()

* using loop and functions (add, avg, and max functions)
* select menu options (1,2,3, and q) and performed opertions based on menu option (ex: add price, get avg price, get max price, quit when user select q).

## Requirements

* Python 3.x
* No external libraries required

## How to Run

Run each Python file individually from the terminal:

```bash
python task_basic_1.py
python task_recursive_2.py
python task_lambda_3.py
python task_map_4.py
python task_filter_5.py
python task_combined_6.py
python task_menu_using_function_7.py

```
