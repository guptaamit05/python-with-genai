# Python File Handling

## Tasks

### 1. Write Sales Orders

* Write sales values to a file.

### 2. Read a File

* Read file content using `read()`, `readline()`, and `readlines()`.

### 3. Append Sales

* Append new sales values and count the file lines.

### 4. Generate a Sales Summary

* Calculate the total, highest, lowest, and average sales.

### 5. Create a Product File

* Collect product names and prices, then save them to a file.

### 6. Read a File Safely

* Read a user-selected file and handle errors.

### 7. Export Discounted Prices

* Apply a percentage to product prices and export the results.

## Requirements

* Python 3.x
* No external libraries required

## How to Run

Open and run `file_handling.ipynb` in Jupyter Notebook or VS Code.
